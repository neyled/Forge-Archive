## 🕰️ About the Archive...

This repository is a **curated collection of PvP mods** for **Minecraft Forge**, dating from around **2013 to 2018** — a period considered by many to be the **golden age of competitive Minecraft**.

These mods were once widely used in custom clients, practice servers, and competitive ladders across the PvP community. Many of them are now **difficult to find**, **no longer maintained**, or scattered across long-dead forums.

This project aims to preserve them for:

- 🧠 **Historical reference**
- 🧪 **Modding research**
- 📼 **Nostalgia**

---

## 📦 Contents

The archive is organized by Minecraft versions.


Inside each folder, you'll find:

- `.jar` mod files
- A brief description, as well as the archived mods build versions
- Original author(s), if known
- Notes on compatibility and usage (if deemed necessary)

## 🛠️ Installation

1. Install the corresponding [Minecraft Forge](https://files.minecraftforge.net/) version.
2. Drop the `.jar` file(s) into your `mods/` folder.
3. Launch Minecraft with the Forge profile.
4. Some mods may require configuration via `config/` or in-game settings.

## 🧭 Why This Matters

Many years ago, Minecraft PvP thrived through Forge mods.  
These tools shaped how players moved, fought, and competed — from **Kohi** and **Badlion**, to many other incredible servers and environments.

But as time passed and clients evolved, many of these mods vanished, or were heavily modified.  
This archive stands to ensure that this era **won't be forgotten nor erased**.

## 🏁 PvP Lives On
